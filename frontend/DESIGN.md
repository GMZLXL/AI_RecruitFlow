# AI RecruitFlow 既有界面约定

Operate模式，继承现有Ant Design界面，不替换视觉身份。主色#1677ff用于主要动作与选中状态；背景#f6f8fb、白色工作面，正文#172334。系统中文无衬线字体，数据使用等宽数字。绿色/橙色/红色状态须有文本。

桌面左导航220px，顶部模拟身份/连接说明，内容最大1550px；小屏使用显式导航按钮与Drawer，主体min-width:0，表格在容器内横向滚动，表单单列。详情通过标签页组织基础信息、面试、Offer、历史。筛选和编辑表单均保留标签，失败保留输入。

复用Ant Design按钮/输入/Select/日期/表格/Drawer/空态；不新增装饰图、展示字体或页面入场动画。图表只表达真实统计并提供文本口径/摘要。约10px圆角继承原配置，间距8/16/24px。

S4继续此系统：看板先筛选与口径，再指标/图表；列表先筛选再明细；移动端优先保留搜索、详情、审核与待办。关闭侧栏后显式按钮仍可打开导航。

AI审核抽屉按操作意图展示必要字段：阶段更新保留目标申请、操作意图、目标阶段和审核说明；新增、面试结果、面试安排只展开各自相关字段。少见的候选人/岗位/面试ID匹配收在“高级匹配”折叠中，默认关闭。390px阶段审核的确认、修正、驳回按钮可在首屏操作，不以展示内部结构代替业务确认。

候选人与申请查询提供“来源渠道”，可直接筛选“演示样本”；该值与其他筛选一起提交后端，并保留在表单中。宽表格在工作面内部横向滚动，不让页面整体横向溢出。

看板图表通过独立的Charts模块按需加载；只注册当前使用的ECharts柱状、折线、漏斗及所需组件/Canvas渲染器。路由页面延迟加载，构建将框架、图表引擎/渲染器、图标和样式运行时分别分包；此边界用于控制首次加载与缓存，不改变统计口径或用示例数据填补空态。

S5沿用上述Operate界面。系统设置中的管理员企微工作面先列接收、发送与后台任务状态，再以标签页组织“接入与用户绑定”“提醒规则”“模拟投稿”；接入指引使用纵向步骤，用户绑定和提醒配置使用有标签的纵向表单。提醒默认关闭，页面明确说明模拟模式、凭证缺失与尚未联调的区别。

配置表单复用“刷新版本，保留草稿 → 对照最新已保存数据与版本 → 保存”的交互；刷新不覆盖正在编辑的字段，加载或读取失败时阻止保存。用户绑定与提醒规则保存后显示明确的成功确认，使用role="status"播报。企微连接状态刷新通过useResource可选的keepPreviousData保留原工作面，使已挂载的标签页与表单草稿持续可用；其他调用仍保持原默认行为。

模拟投稿把持久接收与后台处理分开表达：提交成功显示“已接收，等待后台处理”，提供AI审核入口与接收记录刷新。消息ID在失败后保留供原消息重试，只有“开始新消息”主动生成新ID；接收列表分别显示等待解析、解析中、已处理与失败，接收成功不冒充业务已完成。

通知记录抽为DeliveryQueue，在设置页提供管理员操作，在待办页复用记录展示。状态标签同时给出文字：mock_sent为“模拟发送”，accepted为“平台已接受”，uncertain为“结果不明，需核实”；说明文字明确平台接受不代表收到或已读。只有明确失败或待配置记录向管理员提供重试入口，弹窗要求重试依据；结果不明不显示直接重发。通知表在自身容器内横向滚动并分页。

S5提醒规则界面已留存1440/1024/390px证据（.tools/s5-reminders-1440-fixed.jpg、.tools/s5-reminders-1024-fixed.jpg、.tools/s5-reminders-390-fixed.jpg）；最终界面评审结论为Ship，M1/M2已解决。此结论限于已构建界面，不代表真实企微联调完成。

S6继续沿用Operate与既有Ant Design系统。管理员在系统设置的连接状态下方直接填写“AI接入配置”，使用白色Card、有标签的纵向表单与既有520px表单最大宽度；解析方式、模型名称、API Key、清除选项和变更说明依次排列。小屏保留单列表单，说明与状态自然换行，不新增视觉方向、装饰图或动画。

密钥字段使用无明文切换按钮的密码输入框，已存Key不回显，仅展示是否配置及服务器环境/加密保存来源；草稿不写浏览器存储。Key留空表示保留，保存成功清空密码输入并复位清除选项，以role="status"播报保存版本、Key配置状态及当前解析方式。清除选项明确写出“清除当前Key及环境变量回退（需使用Mock）”，不把清除解释为重新使用环境Key。

AI配置沿用“最新已保存状态与版本 → 编辑草稿 → 保存”的工作面，解析方式与模型的已保存值独立于表单草稿展示。刷新保留正在编辑的模型与Key，409或其他保存失败保留输入并提示先刷新核对；读取中或读取失败时禁用保存。当前模式不允许真实调用时，以文字Alert说明可以保存Key与模型并保持Mock，同时禁用DeepSeek选项；加密存储未就绪时提示管理员并禁用Key输入。配置保存与真实联通验证分开表达，成功提示不宣称已连接DeepSeek。

顶栏根据服务端认证模式显示身份入口：开发模式保留明确标注的模拟身份选择器；非开发认证不展示该选择器，已认证时显示企业身份，认证失败且服务端提供登录地址时显示“企业登录”入口。企业身份标签、登录入口或配置保存均不作为真实SSO/DeepSeek联调完成的证据。

S6 AI配置界面证据为.tools/s6-ai-1440.jpg、.tools/s6-ai-1024.jpg、.tools/s6-ai-390.jpg；独立界面评审最终结论为Ship，无material findings。该记录仅覆盖已构建界面，不表示真实企业登录、DeepSeek调用或Docker容器运行已验收。
