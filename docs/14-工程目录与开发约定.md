# 14｜工程目录与开发约定

## S6 增量目录

- core/{runtime,sso,secret_store,limits,logging,http}.py：启动、会话、加密、限流与日志边界。
- schemas/{ai_settings,operations}.py、services/ai_settings.py、api/v1/operations.py：契约、受管配置和管理路由。
- jobs/runtime.py：DB领导租约/监督，保留sync/wecom业务循环。
- backend/scripts/admin/users.py、operations/{backup,serve,healthcheck}.py、smoke/security.py：授权撤销、备份恢复、容器启动和隔离安全验收。
- frontend/src/features/settings/AISettingsPanel.tsx及test/ai-settings.test.tsx：配置交互，types继续生成。
- deploy/、compose*.yaml、scripts/deploy/compose.mjs：镜像/代理/环境示例和官方Compose封装；密钥、secret目录、本地工具/库均忽略。
- docs/15-安全部署与恢复手册.md：目标环境步骤及实测边界。

S5新增integrations/wecom/{config,callback,sender}.py，services/wecom.py负责持久接收及S2编排，notifications.py负责事实提醒和通知队列，jobs/wecom_worker.py仅调度。schemas/wecom.py为契约源，api/v1/wecom.py处理HTTP边界。无Redis/Celery/新服务；scripts/smoke/wecom.py通过根smoke:wecom运行。

前端features/wecom独立WecomPanel/DeliveryQueue；设置管理接入/规则/绑定，待办复用本人通知。useResource可选keepPreviousData只用于S5保留草稿的配置刷新，旧调用行为不变。刷新不卸载表单，展示最新保存版本供比较，不静默覆盖草稿。

原starter下的前后端已提升到根目录，已有.env、数据库和虚拟环境随目录保留。Git只记录源码/配置，敏感和运行文件仍被忽略。开发命令统一从根目录npm脚本进入，不依赖终端激活状态。

后端依赖方向：api→services→db/integrations。服务层不接收FastAPI Request；Parser只返回提议，不持有业务数据库/工具执行权限。schemas包是唯一数据契约源，内部按领域拆分，包出口统一导出；生成TS禁止手改。

S3 services/sync.py编排领取→事务外IO→独立确认；jobs/sync_worker.py只负责生命周期/周期触发，不包含外部参数。Mock适配器内部事务代表模拟远端，不得复用业务Session；腾讯Schema和字段ID只位于适配器/忽略的诊断文件。

前端页面只通过services调用API；领域类型来自生成文件；跨页面标签/日期呈现在features中复用。S3同步标签/错误文案位于features/sync。不要将新页面继续堆入app/App.tsx，不将操作脚本混入运行时app模块。

常用命令：npm run check、npm run db:upgrade、npm run db:check、npm run contracts:generate、npm run smoke:http。

S4增加schemas/workbench.py（Offer/统计/待办/历史）、services/workbench.py/offers.py和api/v1/workbench.py。前端features/recruitment按筛选、时间、标签、创建/阶段/面试/Offer/历史分文件，features/dashboard独立图表，features/shared/useResource集中取消旧请求；components提供加载/空/错与错误边界。tests在frontend/src/test（Vitest），并加入根check。

演示脚本独立放backend/scripts/demo/seed.py；S4 HTTP验证在scripts/smoke/workbench.py。根命令npm run demo:seed、smoke:workbench、test:api、test:web。PRODUCT.md/DESIGN.md记录已确认产品和已建成界面，不代替后端契约。新页面继续遵循api→service→db/integration与统一生成类型，不堆到main/App中。

后端独立脚本使用模块执行：`python -m scripts.contracts.export`、`python -m scripts.migrations.upgrade_s0 --source ... --destination ...`、`python -m scripts.smoke.http`（工作目录backend）。迁移/脚本通过core/config.py获取稳定根路径，新增目录不应导致到处修改parents[n]。
